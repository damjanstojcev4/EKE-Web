## Current implementation and scope

The audit used the current branch, not the obsolete static article composition. `app/news/[slug]/page.tsx` generates only manifest-backed static slugs, disables dynamic parameters and supplies existing metadata. `PublicArticle` requests `/news/slug/{slug}`; related cards independently request `/news/public/{id}`. It renders a hero, metadata/share row, title, introduction, rich body and an always-expanded related list. Related cards use **h3**, with their original inherited typography. The separate `ArticleSidebar` uses h2, a clipped/masked list, clamped summaries and an expansion button; it has no current production caller. This phase preserves both paths instead of inserting the standalone component into the live article.

`ArticleContent` supports headings, paragraph text runs (strong, external link and pending link) and simple lists. It is also used by `PublicProject`, so its markup and mapping remain byte-for-byte unchanged. `PendingControl` has one direct caller, `ArticleTextRuns`, and two transitive production consumers: News detail and Project detail. Its children/message/label/className API, aria-disabled button, click toggle, blur closing and hover/focus-within visibility remain unchanged.

Ordinary styling now uses exact Tailwind v4 utilities in `PublicArticle`, `ArticleSidebar`, `ArticleShare` and `PendingControl`. Five feature-local class strings in `article-styles.ts` share only the genuinely common sidebar/card/image/summary presentation. No unnecessary wrapper components were added. `article.module.css` owns the remaining scoped rules. News feature components no longer import any route-directory stylesheet. Both old News route modules have been deleted only after their replacements were validated while the old modules were unimported.

Header/Footer, the News listing, Project source/styles, shared UI, global CSS, tokens, API clients, publication logic, content contracts, metadata and static slug generation are unchanged. [Source audit](news-detail-baseline/source-audit.json) records hashes and normalized AST comparisons: after removing styling imports/className attributes, all four migrated components retain their original logic/markup/handlers.

## Styling decisions and CSS counts

No breakpoint was rounded to a Tailwind default. News retains **max-width:768px**, **769–1100px** and base fallback behavior outside those ranges; global 700/701 scaling and 1100/1101 boundaries are tested too. Exact calc values, mobile clamps, radii, translucent colors, gradient stops, backdrop blur, typography and crop ratios are preserved. Existing brand/surface tokens are reused.

Important paragraph/heading margin and link-decoration utilities preserve precedence over the existing unlayered global resets. Grid alignment uses literal `[align-items:start]`, preserving the original computed value instead of the visually equivalent flex-start/flow-start alias. Body border color is set only on the top border, preserving the invisible side-border colors too. These computed-only discrepancies were found while all 84 initial PNGs already matched, then corrected; references/thresholds were not changed.

PendingControl is completely utility-styled. The arbitrary group hover variant deliberately retains the original unconditional `:hover` selector rather than adding Tailwind's hover-capability media condition. Native click/focus/blur behavior, tooltip coordinates, transform, shadow, dimensions and typography remain exact in both inherited contexts. None of its former **21 declarations** remains.
